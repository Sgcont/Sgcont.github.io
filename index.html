Aplicação de aprendizado de máquina implementada em C

Análise da Criminalidade no Rio de Janeiro

Python, SVD, PCA, K-Means — projeto da disciplina Computação Científica e Análise de Dados (COCADA)

  • Aplicação de Decomposição em Valores Singulares (SVD) e Análise de Componentes Principais (PCA) sobre dados de criminalidade do Instituto de Segurança Pública do Rio de Janeiro (ISP-RJ).
  • Uso de K-Means para agrupamento de regiões com padrões de criminalidade semelhantes e cálculo de variância explicada para avaliação da qualidade da redução de dimensionalidade.
  • Construção de visualizações para identificar tendências e padrões espaciais de criminalidade entre bairros.
  • Versionamento com Git/GitHub em colaboração com o grupo.

Transportes Rio — Oferta de Transporte Público e Demografia

SQL, MySQL, Python (Geopandas), HTML — projeto da disciplina Banco de Dados I (ICP489)

  • Modelagem e implementação de um banco de dados relacional em MySQL correlacionando dados GTFS de transporte público com informações demográficas (população, densidade) por região do Rio de Janeiro.
  • Desenvolvimento de consultas SQL (joins, subqueries, agregações) para determinar as regiões com maior oferta de transporte.
  • Construção de aplicação web em Flask com mapa interativo (Leaflet.js) permitindo consultar, a partir de um ponto de partida, quais destinos são acessíveis.
  • Uso de Geopandas para tratamento e cruzamento de dados geoespaciais.
  • Colaboração via Git/GitHub em equipe, com uso de branches, merges e pull requests ao longo do desenvolvimento.
