Prevendo Notas Futuras (ML)

Um modelo simples de regressão linear, rodando em Python de verdade dentro do navegador (via Pyodide), treinado com as minhas próprias notas dos períodos 1 a 4. Para cada disciplina que já cursei, ele relaciona a média das notas dos pré-requisitos oficiais (grade curricular do IC/UFRJ) com a nota que tirei nela — e usa essa relação para estimar disciplinas do 5º e 6º período que ainda não cursei.

Sobre a margem de erro: com uma base de dados pequena (uma única pessoa, poucas dezenas de disciplinas), uma divisão fixa de 80% treino / 20% teste feita uma única vez seria pouco confiável — o resultado dependeria muito de sorte na divisão. Por isso o modelo usa Leave-One-Out Cross-Validation (treina deixando uma disciplina de fora por vez, testa nela, e repete para todas) para estimar o erro típico, e converte isso numa margem de erro com 99% de confiança (via distribuição t de Student). Quanto mais larga a margem, menos essa relação (nota de pré-requisito → nota futura) realmente prevê o resultado no meu histórico.
